# Aureon Frontend

The frontend for the Aureon project, built as a premium, immersive AI command center landing experience.

## Tech Stack

- **Framework**: Next.js 15
- **UI Library**: React 19
- **Styling**: Tailwind CSS v4, PostCSS
- **Animations**: Framer Motion
- **3D Rendering**: React Three Fiber, Drei, Three.js
- **Language**: TypeScript 5.5

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy the environment variables example and configure it:
   ```bash
   cp .env.example .env.local
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the application for production.
- `npm run start`: Starts the production server.
- `npm run lint`: Runs ESLint.
- `npm run type-check`: Runs TypeScript compiler check.
- `npm run format`: Formats code using Prettier.
